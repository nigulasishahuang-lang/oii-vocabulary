# oii背词

![oii背词 Logo](assets/oii背词-64.png)

oii背词是一个离线运行的 Windows 英语学习工具。可以浏览词条、搜索当前分类、隐藏中文释义，或把词条加入待复习。在复习列表中可以设置复习标记、标记未掌握的词，并把未掌握词汇导出为可编辑的 Word 文档。

## 在 Windows 上构建

需要 Windows 10 或 11、系统自带的 .NET Framework 4.8 或 4.8.1，以及可通过 `py -3` 或 `python` 启动的 Python 3.8 或更高版本。构建无需额外的 NuGet 或 Python 软件包，也无需安装 Microsoft Word。

在项目目录打开 PowerShell，运行：

```powershell
.\build.ps1 -Test
```

构建会从源码生成演示词库、编译程序并运行基础自测。完成后，双击 `dist\oii背词.exe`。在交互式 Windows 桌面上，可运行 `.\build.ps1 -UiTest` 验证长难句、词条检索、复习操作和重启后恢复进度。自测使用临时存档。

## 试用

- 在阅读、听力、高频难词、进阶短语和长难句之间切换。长难句支持按关键词搜索。
- 用方向键或 A / D 翻条，用空格切换中文释义，在词条页面按 F 或句号加入待复习。
- 在待复习列表中设置复习标记。左 Alt 跳到当前分类的标记。
- 在待复习列表中点击「标为仍未掌握」，然后在「未掌握复习」中浏览或导出。

浏览进度、复习记录和界面设置默认保存在 Windows 的「文档」下的 `oii背词数据` 文件夹。软件可自行离线使用，导出位置由你选择。

## 演示词库和许可

演示包包含 18 条记录，覆盖 6 个内置分类。例句、译文和结构说明为本项目编写，频次和覆盖数为测试筛选而设。待复习中的两条初始记录用于演示，可直接移除。详见 [数据来源](data/README.md)。
